# 0009 · 노션 문제 보드와 문제·할 일·질문 함께 보기

- 상태: 채택 · 2026-11-24 · 결정: FE1

## 예전 설계
노션 총괄 보드에는 할 일(TODO)만 카드로 올렸다. "남은 일"을 물으면 known-issues의 할 일만 보여주고, 문제(ISSUE)와 질문(ASK)은 따로 물어야 했다.

## 바꾼 이유
- 고쳐야 할 문제가 할 일 목록과 노션에 보이지 않아, 투두만 보면 심각도 높은 문제를 놓칠 수 있다.
- 총괄 보드에 섞으면 할 일 개수와 완료일 통계에 문제가 함께 잡히고, 문제에는 심각도가 필요하다.

## 지금 방식
- 노션 "책다듬이" 페이지에 **문제 보드**를 따로 둔다. 열린 문제를 모두 올리고 심각도를 표시한다.
- 질문은 노션에 올리지 않는다. 수가 적고 회의에서 정하면 끝나는 것이라, 물어볼 때 목록으로 보여준다.
- "todo 보여줘"·"남은 일"·"내 파트"를 물으면 **문제 → 할 일 → 질문**을 모두 보여준다.
- 기준은 known-issues다. 노션은 보기용이고, 다르면 known-issues에 맞춘다.
- 저장소가 공개라, 보안 문제는 known-issues와 노션에 악용 방법 없이 요약만 적는다.

## 영향
- 바뀐 문서: skill `issue-log`, [conventions/harness.md](../conventions/harness.md), 루트 `AGENTS.md` 4장
- 문제를 바꿀 때 known-issues와 노션 두 곳을 맞춰야 한다. 노션이 연결되지 않은 사람은 known-issues만 고치므로 가끔 대조가 필요하다.
