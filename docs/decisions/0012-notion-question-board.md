# 0012 · 노션 질문 보드

- 상태: 채택 · 2026-11-25 · 결정: FE1

## 예전 설계
질문(ASK)은 known-issues에만 두고 노션에는 올리지 않았다 ([0009](./0009-notion-issue-board.md)). 수가 적고 회의에서 정하면 끝난다고 봤다.

## 바꾼 이유
- 질문이 12개로 늘었고, 답이 없어 PR 병합을 기다리는 경우가 생겼다 (PR 28, 35).
- 정할 사람이 자기 차례인 것을 알기 어렵다. 노션 카드 비고에는 번호만 있고, 이 질문들은 PR 작성자가 아닌 파트도 답해야 한다.

## 지금 방식
- 노션 "책다듬이" 페이지에 **질문 보드**를 따로 둔다. 열린 질문을 모두 올리고 정할 사람·관련 항목·기한을 보인다. 문제·할 일 보드와 섞지 않는다.
- 나누는 기준은 "답이 정해져 있는가"다. 맞는 동작이 분명하면 문제나 할 일, 사람이 정해야 하면 질문이다.
- 질문 하나에 정할 것 하나만 적는다. 문제나 할 일과 같은 내용이면 질문을 따로 두지 않고 그 항목의 비고에 쓴다.
- 정해지면 known-issues 4장 "해결됨"에 결정을 적고, 만들 것이 생기면 문제·할 일·스펙으로 옮긴다. 코드 병합을 기다리지 않는다.
- 기준은 known-issues다. 노션은 보기용이고, 다르면 known-issues에 맞춘다. 노션에 적힌 답은 담당자에게 확인한 뒤 반영한다.

## 영향
- 바뀐 문서: skill `issue-log`, [conventions/harness.md](../conventions/harness.md), [0009](./0009-notion-issue-board.md)
- 질문을 바꿀 때도 known-issues와 노션 두 곳을 맞춰야 한다. 노션이 연결되지 않은 사람은 known-issues만 고치므로 가끔 대조가 필요하다.
