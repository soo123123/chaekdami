# 001 · 보상(BE2) 브랜치 병합과 프론트 연결 — Requirements

> 범위: `fix/integration2`(BE2 보상) 로컬 병합 + FE1·FE2 연결 + 부스터 부분 적용
> 기준 코드: main `7d3e991` + `fix/integration2` `8b13aaa`
> 작성일: 2026-11-22

## 1. 배경

- BE2가 `fix/integration2`에서 보상 구조를 바꿨지만 main에 병합되지 않았다.
  - 독서 저장 시 보상·퀘스트·D-day를 처리하지 않고, 독서 완료 화면이 `POST /api/rewards/reading-sessions/{id}`를 불러야 처리한다.
  - 연속 독서 기준을 D-day 달력(`dday_records`) 하나로 통합했고, 달력은 서버만 기록한다.
  - 경험치 부스터 사용 API(`POST /api/rewards/boosters/use`)를 추가했다.
- 프론트는 옛 구조 그대로라, 백엔드만 병합하면 경험치·퀘스트·D-day 기록이 모두 멈춘다.

## 3. 요구사항

### R1. 병합
- R1.1 GitHub의 `fix/integration2`를 현재 로컬 브랜치에 병합한다. (충돌 없음 확인됨)

### R2. 세션 번호 전달 (FE1)
- R2.1 독서 저장 응답의 세션 번호(`id`)를 저장 결과에 `sessionId`로 담는다.
- R2.2 독서 완료 화면으로 이동할 때 `sessionId`를 라우트 파라미터로 넘긴다.
- R2.3 개발용 Mock 저장 결과에는 `sessionId`가 없다 (보상 호출 안 함).

### R3. 독서 완료 화면 (FE2)
- R3.1 `sessionId`가 있으면 진입 시 보상 API를 한 번만 호출한다. (같은 화면에서 중복 호출 금지)
- R3.2 경험치, 레벨, 경험치 바, 연속일, 퀘스트 보상 코인은 보상 API 응답 값으로 표시한다.
  - 획득 경험치 = 독서 경험치 + 사진 보너스 경험치 + 이번에 달성한 퀘스트 경험치
  - 오늘의 보상 코인 = 이번에 달성한 퀘스트 재화 + 레벨업 승급 재화
- R3.3 호출 중에는 보상 영역만 로딩으로 두고 나머지는 바로 그린다.
- R3.4 실패하면 보상 영역에 안내 문구와 "다시 시도" 버튼을 보여준다.
- R3.5 `baseGranted: false`(이미 받은 세션)면 같은 값을 보여주고, "+N exp" 같은 획득 강조 대신 "이미 받은 보상" 안내를 보여준다.
- R3.6 `leveledUp`이면 "레벨 업!"을 표시한다.
- R3.7 사진 보너스는 `photoBonus.granted`일 때만 표시한다.
- R3.8 `sessionId`가 없으면(미리보기 등) 기존처럼 조회만 한다.

### R4. D-day 달력과 연속일 (FE2)
- R4.1 D-day 달력의 날짜를 눌러도 기록이 바뀌지 않는다. (선택 표시만)
- R4.2 목표 저장 요청에 달력 기록을 보내지 않는다.
- R4.3 홈, 마이페이지, 레벨, 독서 통계, D-day 화면의 연속일은 서버의 `currentStreak`(D-day 화면은 `longestStreak`도)를 쓴다.
- R4.4 읽은 날 수·방어한 날 수 같은 집계는 달력 기록으로 계속 계산한다.

### R5. 부스터 (FE2 + BE2)
- R5.1 상점의 EXP 부스터 영역에 보유 개수와 "사용하기" 버튼을 둔다. 보유 0개면 비활성.
- R5.2 사용하면 `POST /api/rewards/boosters/use`를 부르고, 끝나는 시각과 남은 개수를 반영한다.
- R5.3 상점과 레벨 화면에 부스터 적용 중이면 끝나는 시각을 표시한다.
- R5.4 (BE) 독서 시간 중 부스터가 적용된 시간 비율만큼만 2배를 준다.
  - 예: 60분 독서 중 마지막 20분만 부스터 → 독서 경험치의 1/3만큼 추가

### R6. 검증과 커밋
- R6.1 백엔드 테스트, 프론트 타입 검사·린트를 실행한다.
- R6.2 병합 커밋, 백엔드 커밋, 프론트 커밋으로 나눠 로컬에 커밋한다.

## 4. 알려진 제한 (이번 범위 밖)
- 완료 화면을 열지 못하면 그 세션의 보상과 D-day "읽은 날"이 기록되지 않는다. (나중에 BE2 정산 기능 필요)
- 사진 인증 보너스는 BE1 인증 조회가 연결되기 전까지 항상 미지급이다.
- 공유 DB의 `streak_logs`는 사용하지 않지만 남아 있다.
- 병합 전 저장한 세션도 보상 API로 경험치를 받을 수 있다.
