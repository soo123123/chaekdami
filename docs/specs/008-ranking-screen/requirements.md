## 2. 요구사항

### R1. 랭킹 화면으로 이동

사용자로서, 어디서든 쉽게 순위를 보기 위해 하단 탭에서 랭킹으로 가고 싶다.

- **R1.1** 하단 탭바를 보면, 커뮤니티와 마이페이지 사이에 랭킹 탭이 있다.
- **R1.2** 랭킹 탭을 누르면, 랭킹 화면이 열리고 랭킹 탭이 선택된 모양으로 표시된다.
- **R1.3** 다른 탭과 랭킹 탭을 오가면, 기존 탭처럼 화면 전환 애니메이션 없이 바뀐다.
- **R1.4** 기존 4개 탭을 누르면, 이동 동작은 지금과 같다.

### R2. 이번 주 순위 보기

사용자로서, 다른 사람과 비교하기 위해 이번 주 순위를 보고 싶다.

- **R2.1** 랭킹 화면을 열면, 독서 시간 랭킹이 먼저 보이고, 화면 위쪽 탭으로 경험치 랭킹과 전환할 수 있다.
- **R2.2** 랭킹을 보면, 서버가 준 이번 주 시작 날짜와 끝 날짜가 표시된다.
- **R2.3** 랭킹을 보면, 서버가 준 순서대로 최대 30명의 순위·닉네임·레벨·점수가 표시된다.
- **R2.4** 점수가 같은 사용자가 있으면, 서버가 준 순위를 그대로 표시한다 (예: 1, 2, 2, 4).
- **R2.5** 독서 시간 랭킹을 보면, 초 단위 점수가 시간·분·초로 바뀌어 표시된다 (순위가 초 합계로 갈리므로, ASK-19).
- **R2.6** 목록에 내가 있으면, 내 항목이 다른 항목과 구분되어 표시된다.
- **R2.7** 1~3위 항목을 보면, 목록 안에서 메달 아이콘으로 강조된다.

### R3. 내 순위

사용자로서, 상위 30명이 아니어도 내 위치를 알고 싶다.

- **R3.1** 랭킹을 보면, 30위 밖이어도 내 순위와 이번 주 점수가 표시된다.
- **R3.2** 이번 주 내 점수가 0이면, 내 순위는 "–"와 "이번 주 기록이 없어요"로 표시된다 (ASK-20).
- **R3.3** 목록을 스크롤해도, 내 순위는 목록 아래에 고정되어 계속 보인다.
- **R3.4** 내 점수가 있는데 순위가 없으면(관리자처럼 집계 대상이 아님), 내 순위는 "–"와 "집계 대상이 아니에요"로 표시된다 (ASK-20).
- **R3.5** 내 순위가 다른 사람과 같으면, 내 순위 줄에 "공동"이 함께 표시된다. 목록 마지막 순위 이내인데 목록에 내가 없을 때(30명에서 잘린 동점)도 공동으로 본다 (ASK-16).

### R4. 불러오기 상태

- **R4.1** 순위를 처음 불러오는 동안에는, 로딩 표시가 보인다.
- **R4.2** 불러오기에 실패하면, 오류 안내와 다시 시도 버튼이 보이고, 누르면 다시 불러온다.
- **R4.3** 이번 주 순위에 아무도 없으면, 빈 목록 안내가 보인다.
- **R4.4** 다른 화면에 갔다가 랭킹 화면으로 돌아오면, 순위를 새로 불러온다.
- **R4.5** 출시용 앱에서는, 예시 데이터가 실제 순위로 보이지 않는다.
- **R4.6** 받은 순위의 주(한국 날짜)가 끝났으면, 앱으로 돌아올 때 다시 불러오고, 다시 불러오지 못하면 "지난주 순위예요 · 다시 불러오기" 안내가 보인다 (TODO-44).
